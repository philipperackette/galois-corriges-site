Théorie de Galois — Philippe Rackette

Mode d'emploi

Ce site contient les solutions détaillées des exercices proposés dans le manuel Théorie de Galois — Un parcours rigoureux et pédagogique.

Les corrigés sont organisés par chapitre. Chaque page propose la solution complète, avec les étapes intermédiaires. Ils sont destinés à être consultés après avoir travaillé l'exercice : la solution n'a de valeur que si elle confirme ou corrige un raisonnement déjà esquissé.

Pour tout retour sur les corrigés ou les exercices, contacter l'auteur via la page GitHub du projet.
